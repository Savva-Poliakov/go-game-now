# Go Game Now (GGN)

Программа для Windows — игра в Го против ИИ с локальным движком.

## Возможности
- Игра на досках 9×9, 13×13, 19×19
- Один ИИ-движок с уровнями силы по системе кю/дан
- Работает полностью локально, без интернета

## Установка
Скачайте установщик из [Releases](../../releases) и запустите.

## Статус проекта
В разработке (MVP).
